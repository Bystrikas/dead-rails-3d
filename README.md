# Dead Rails: Last Train

Prototipo 3D survival western per browser, realizzato con TypeScript, Three.js e Vite. È un gioco originale ispirato al genere survival su rotaia, non un clone ufficiale e non usa asset Roblox.

## Requisiti
- Node.js 20 o superiore
- npm

## Avvio
```bash
npm install
npm run dev
```

## Build produzione
```bash
npm run build
npm run preview
```

## Comandi
- **W A S D**: movimento
- **Mouse**: mira
- **Click sinistro**: spara
- **R**: ricarica
- **Shift**: corri
- **Esc**: pausa / libera il mouse

## Nota tecnica
Il progetto usa geometrie e materiali procedurali, quindi può essere eseguito senza scaricare modelli 3D esterni.
